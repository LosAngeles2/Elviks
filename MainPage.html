📦 Как установить

Для Windows:

  1. Нажми на кнопку «Скачать для Windows» выше и дождись загрузки файла.
  2. Открой скачанный файл .msix двойным кликом.
  3. Windows может показать синее окно «Система Windows защитила ваш компьютер».
  4. Нажми «Подробнее» → «Все равно установить». Это нормально для новых приложений.
  5. Готово! Ищи Elviks в меню «Пуск».

Для Android:

  1. Нажми на кнопку «Скачать для Android» выше.
  2. Открой скачанный файл .apk на телефоне.
  3. Если система заблокирует установку, перейди в Настройки → Безопасность → Разрешить установку из неизвестных источников (для твоего браузера или файлового менеджера).
  4. Вернись и нажми «Установить».
